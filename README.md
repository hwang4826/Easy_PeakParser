# 🚀 Easy_PeakParser v1.0.0

**Easy_PeakParser**는 서로 다른 장비에서 독립적으로 측정된 MFC 유량 제어 기록과 분광기 파장(Peak) 데이터를 시간(Time) 기반으로 정밀하게 동기화하고, 분석에 최적화된 엑셀 파일로 자동 가공해 주는 광학/반도체 하드웨어 데이터 전처리 올인원(All-in-One) 툴입니다.

## 🎯 개발 동기 (Motivation)

* 실험실 환경에서 MFC(질량유량제어기)는 Ar, N2 등 다양한 가스의 유량 셋포인트와 실제 유량값을 0.3초 단위로 방대하게 기록합니다.


* 이와 동시에 분광 장비는 각 파장별 피크 데이터를 별도의 CSV 파일로 기록하게 됩니다.


* 이 두 가지 이기종 데이터를 엑셀에 띄워두고, 유량이 변경되는 시점을 찾아 시간대를 일일이 대조하며 특정 구간에 색을 칠하는 수작업은 엄청난 시간과 에너지가 소모됩니다.


* 연구자가 단순 반복 작업(노가다)에서 벗어나 핵심 '데이터 분석'에만 집중할 수 있도록, 클릭 한 번으로 안정화된 데이터 구간만 쏙쏙 뽑아주는 스마트 자동화 툴을 개발하게 되었습니다.



## ✨ 주요 기능 (Features)

* **이기종 데이터 정밀 Time-Sync 매칭**
* 유량이 고정된 '배경가스'와 유량이 변화하는 '제어가스'를 프로그램이 스스로 판별합니다.


* MFC 유량 변경 시점과 Peak 기록 시점의 시간차를 밀리초 단위로 계산하여 1:1로 매칭합니다.


* 0 SCCM에서 20 SCCM 등 다음 사이클 준비를 위해 초기화되는 시점의 피크 파장 데이터도 누락 없이 저장합니다.




* **스마트 데이터 필터링 및 하이라이팅**
* `[Ch1 Header]` 등 불필요한 장비 공통 메타데이터를 깔끔하게 지우고 데이터 영역을 최상단으로 끌어올립니다.


* 기존 `Ch1_x`로 표기되던 파장 헤더를 `315.9 / N2`와 같이 직관적인 (파장 / 원소명) 형태로 자동 치환합니다.


* 불필요한 모든 데이터 행은 삭제하고, 유량 변경 직전 가장 안정화된 데이터 10줄(노란색)과 유량 변경 시점 데이터 1줄(빨간색)만 추출하여 반복 출력합니다.




* **동적 엑셀 서식 자동 적용 (Auto-Formatting)**
* A열 빨간색 줄(유량 변경점)에는 "유량 변경"이라는 직관적인 텍스트를 자동 삽입합니다.


* 데이터 파악이 불필요한 `RecipeName` (예: 260126_1632) 열을 찾아 통째로 삭제합니다.


* Timestamp 형식을 `2026:09:16:14:18:37:737`에서 가독성이 높은 `260916 14:18:37.436`으로 변경합니다.


* B1~H1 셀을 넓게 병합하여 "배경가스 Ar 200 sccm + 제어가스 N2 0~20 sccm(Δ1 sccm)" 등의 직관적인 통합 메타데이터를 적어줍니다.


* 측정일과 수정일 정보는 데이터 바로 위(D2~G2)에 깔끔하게 배치합니다.


* 측정된 원소 종류(N2, O, Ar 등)가 변경될 때마다 진한 색상(노란색/빨간색)과 옅은 색상(옅은 노란색/옅은 빨간색)이 자동으로 교차 적용되어 가시성을 극대화합니다.


* 데이터 스크롤 편의를 위해 D4 셀을 기준으로 상단 3행과 좌측 3열의 틀 고정을 자동 적용합니다.




* **안전망 및 오류 방지 시스템**
* 두 가지 파일(MFC 기록, 파장 기록)이 모두 입력되어야만 실행되도록 설계하여 사용자 실수를 방지합니다.


* 측정이 끝난 이후의 잉여 데이터가 도돌이표처럼 무한 반복 출력되는 버그를 원천 차단했습니다.


* 시간대가 엇갈려 매칭된 데이터가 없을 경우, 내용이 비어있는 깡통 엑셀 파일이 만들어지지 않도록 방어하고 실패 리포트를 제공합니다.


* 파일명은 `yyMMdd_HHmm_Ar_B200_N2_C20` 형식으로 자동 저장되며, 배경가스(B)와 제어가스(C)의 역할과 유량을 파일명만 보고도 즉시 식별할 수 있습니다.





## 🛠️ 사용 방법 (How to Use)

1. `Easy_PeakParser.exe` 파일을 실행합니다.
2. **[1. MFC 유량 제어 기록 파일]** 창에 `*.csv` 포맷의 MFC 로깅 파일을 드래그 앤 드롭합니다.


3. **[2. 파장 기록 파일]** 창에 장비에서 추출한 `*.csv` 포맷의 Peak 스펙트럼 파일들을 드래그 앤 드롭합니다. (다중 선택 및 대량 일괄 처리를 지원합니다.)


4. 하단 저장 설정의 '파일명' 칸을 비워두면 기본 규칙(yyMMdd_HHmm_가스정보)이 자동 적용됩니다.


5. **[Process & Save All]** 버튼을 누르고 결과물이 저장될 폴더를 선택하면, 단 몇 초 만에 모든 데이터가 정밀 매칭 및 서식화된 `*.xlsx` 엑셀 파일들로 생성됩니다.

## 📈 기대 효과 (Benefits)

* **압도적인 시간 절약:** 파일 한 개당 수십 분 이상 소요되던 데이터 탐색 및 하이라이팅 수작업을 1초 이내로 단축시킵니다.
* **휴먼 에러(Human Error) 제로:** 연구자가 눈으로 직접 시간을 대조하며 발생할 수 있는 매칭 실수나 색상 표기 누락을 완벽하게 제거합니다.
* **인수인계 및 공유 최적화:** 파일명만으로 가스의 종류, 배경/제어 역할, 유량 정보를 직관적으로 파악할 수 있어 폴더 관리가 용이해지고 연구실 내 데이터 공유 및 인수인계의 효율성이 비약적으로 상승합니다.
